# Decisioni e log

## Scopo

Raccogliere le decisioni operative non sufficientemente ampie per un ADR e il registro delle attività rilevanti.

## Formato minimo

| Data | Decisione o evento | Motivazione | Impatto | Riferimenti |
|---|---|---|---|---|

## Regola

Non usare questo file per nascondere modifiche tecniche: collegare sempre file, query, test o evidenze.
