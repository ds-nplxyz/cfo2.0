# Configurazione MCP Trino

## Scopo

Documentare la configurazione necessaria per interrogare Trino tramite MCP senza esporre segreti.

## Contenuti da inserire

- Endpoint e ambiente, senza password o token.
- Cataloghi e schemi autorizzati.
- Metodo di autenticazione descritto in modo sicuro.
- Limiti e timeout.
- Query di verifica non distruttive.

## Regola

I valori sensibili restano nel gestore delle credenziali o nelle variabili d’ambiente locali.
