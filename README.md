# CFO 2.0

## Scopo

Questo repository documenta e realizza il progetto CFO 2.0: dati contabili, Profit & Loss, riclassificazione, controlli mensili, allocazione dei costi e dashboard.

## Regole base

- Documentare prima di implementare.
- Separare dati sorgente, trasformazioni, risultati e presentazione.
- Non salvare credenziali o segreti nel repository.
- Registrare decisioni, modifiche e risultati verificati.

## Stato iniziale

La struttura è stata predisposta. I contenuti operativi devono essere compilati con dati reali e verificati.
