# Esempi di query validate

## Scopo

Conservare query che hanno prodotto risultati verificati e riutilizzabili.

## Scheda per ogni query

- Nome e obiettivo.
- SQL.
- Ambiente e data di verifica.
- Parametri.
- Risultato atteso.
- Confronto con fonte ufficiale.
- Limitazioni note.
